Key HTML Tags

5 HTML Tags I have learned:

<form>
Is used to create an interactive area on a web page for collecting user input and sending it to a server for processing.
<a>
Is used to define a hyperlink.
<abbr title="...">
Is used to define an abbreviation or an acronym within web content.
<strong>
Is used to indicate that the enclosed text has strong importance, seriousness, or urgency.
<address>
Is used as a semantic element to define the contact information for the author or owner of the nearest ancestor or element.
